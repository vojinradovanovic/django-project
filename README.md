## **Running the project**
- In order to run the project, you need to have django installed. Follow the procedures outlined on [this link](https://docs.djangoproject.com/en/6.1/intro/install/).
- After downloading all the files, to view the project on a local server, open your Terminal app from the `django-project` folder. Then, run the command `python manage.py runserver`. The terminal will then create a link to a local host (e.g. http://127.0.0.1:8000/), which you can open in a browser of your choice.
